Workspace OS Manual

One window where your documents, mail, calendar and browser live together with a team of agents that do real work, and where every result waits for you to keep or undo it. This manual walks every surface with a real screenshot and says what it does for you, what you can do there, and how an agent uses it.

Screenshots taken from the built app on a seeded demo workspace. Nothing is mocked; where a feature is a preview or placeholder, it says so.

What Workspace OS is

A desk for people who run things: accounts, projects, a team. One desktop app where the work you already do and the agents that help you do it share the same window.

Most of a manager's day is spread across a dozen windows: the proposal in Word, the forecast in Excel, the deck, the inbox, the calendar, a browser full of tabs, and lately a chat window where an AI writes text you then carry back by hand. Workspace OS folds these into one place. Documents open in a real office engine, mail and calendar are native, the browser is built in, and a team of agents works inside the same folder you do. When an agent finishes something, it is a file on your disk and a card in your feed, not a paragraph to copy.

The unit of work is a case: a renewal, a forecast, a hire. A case gathers its notes, files, mail and calendar dates, and the app keeps track of which one is waiting on you. Today tells you that the moment you sit down.

One window

Word, Excel, PowerPoint, CSV, notes, mail, calendar and the web, side by side as tabs. Nothing to switch to.

Agents that do real work

Specialists you describe in a sentence. They read your files, drive the browser, draft replies, build decks and spreadsheets, and run on a schedule while you are away.

Keep or undo

Every agent run lands as a checkpoint. You see what changed, then keep it or roll it back in one click. Nothing is silently overwritten.

Numbers that stay live

A figure lives in one spreadsheet and flows into the document and the deck that quote it. Change the source, and everything downstream follows.

Sign in once

Connectors remember your accounts securely. Agents inherit the session, so the CRM, the drive and the mailbox are simply there.

It remembers

Knowledge links your notes; Memory holds what is worth keeping across sessions and lets you correct it. The desk assistant sees all of it.

The landscape and the dock

The app opens on your team: a calm landscape of agents, with your latest work standing in front of them and a dock that takes you everywhere.

What you can do

  • Scroll, drag or swipe through your agents; click one to step closer, ← → to move between them, Esc to go back.
  • Click a work card to continue that case or session where you left it.
  • Switch Team and Today at the top right; All work opens Cases; Add agent creates a specialist.
  • Use the project switcher (top right) to open a sub-project, a recent workspace, or Open folder….

The dock

Overview · Chat · Apps · Inbox · Cases · Library · Menu · Terminal. Esc returns to the overview from anywhere on the landscape.

The stage

Documents, mail, calendar and the browser open on the stage: a flat working surface with the rail on the left (⌘B shows or hides it) and the same dock in its top bar. Settings → Open on chooses Landscape or Stage at start.

Today

Coming back: what happened while you were away, the one thing waiting on you, and an assistant that sees the whole desk.

What you can do

  • Open the waiting item, or put it off with Not now; with nothing waiting, Today offers your agents.
  • See the next 48 hours of calendar and the mail that waits for a reply.
  • Read While you were away: what agents and others added to the workspace.
  • Open recent files and pages; ask the workspace anything, with @ to mention a file.

Reach it

Overview → Today at the top right · Menu → Home. Today replaces the Home screen of earlier versions.

Files

Your workspace folder, with the tree on the left and the file open beside it.

What you can do

  • Browse the tree, filter by name, create files and folders, trash and restore.
  • Open anything: the right editor comes up by file type (see the next sections).
  • Preview in place, then Open full for a stage tab of its own.
  • Reveal a file in Finder (Explorer on Windows); drag files in.
  • Find a file by name or by what is inside it from the Library; right-click a file → Add to the wiki.

Reach it

Rail Files · Menu File ▸ Open Folder ⌘O, Open Recent, Close Folder ⇧⌘W · Go to file ⌘P.

Agents

Every agent runs inside this folder. Files it creates appear in Today and the Library the moment they land on disk.

Word documents

A native word processor in the window: real .docx, edited in place by the LibreOffice engine, with a ribbon that speaks Word.

What you can do

  • Type, format, style; Home, Insert, Layout, References, Review and View tabs, plus Table and Picture tabs that appear with the selection.
  • Right-click anywhere: the engine's menu for that target, with submenus, check marks and keyboard navigation.
  • Every dialog the engine has (Paragraph, Character, Table of contents, Bookmark, Columns, Sort…) opens as a native-looking dialog of ours; message boxes too.
  • Review: comments and tracked changes in a panel; margin anchors open the thread.
  • Layout: margins, orientation, header and footer, page numbers, columns, a watermark picker, line numbering. View: Normal, Web, Print preview, and the ruler.
  • Pictures wrap and anchor from their tab; shapes get fill, outline, arrange, rotate and flip, and a rotate handle on the canvas.
  • The native menu bar mirrors LibreOffice's Edit, View, Insert, Format, Styles, Table and Tools menus; ⌘K runs any of them by name.
  • Export to PDF or Word; Save writes the .docx back, faithfully.
  • Place a live metric in the text; it stays in step with the spreadsheet it came from.

Also opens here

.doc, .odt. PDFs open in a viewer with annotation and page tools.

Agents

An agent builds real documents with wos-gen docx from a JSON spec; the file opens in a tab when it lands.

Spreadsheets

Real .xlsx with formulas, formats and sheets, rendered fast enough to feel native.

What you can do

  • Edit cells and formulas; AutoSum; number formats; borders; conditional formatting; data validation; find and replace; a name box for jumping to and naming ranges.
  • Fill handle at the selection corner continues a series; ⌘-wheel and pinch zoom; a floating toolbar on every selection.
  • AutoFilter arrows with the engine's own dropdown; Sort that asks whether to expand the selection; Data ▸ Group and Outline with a −/+ bar.
  • Cell styles and Format as table on Home; a Layout tab (margins, orientation, headers and footers, breaks, print area); a Formulas tab (calculation and auditing); Data tools (text to columns, duplicates, consolidate, goal seek, solver, scenarios).
  • Right-click cells, sheet tabs and headers for the engine's menus; sheet tabs rename, reorder by drag, hide and colour.
  • The status bar sums and averages the selection; View ▸ Page break shows the print layout.
  • Turn a cell into a live metric that flows into decks, documents and mail.

Also opens here

.xls, .ods, and CSV/TSV (next section).

Agents

wos-gen xlsx builds a workbook; wos-metric create --source "book.xlsx!Sheet1!B2" binds a cell as the source of truth.

Presentations

Real .pptx with a slide rail, speaker notes, and a Present mode.

What you can do

  • Reorder slides by drag, edit text and shapes, add speaker notes, present full screen; the slideshow advances on its own when a transition says so.
  • Shapes: a Shape tab appears with the selection (fill, outline, arrange, rotate and flip, group, duplicate); drags snap to smart guides on other shapes and the slide centre; a rotate handle sits above the box.
  • Slide tables get a Table tab and grips for rows and columns; right-click a thumbnail for new, duplicate, layout, hide, move, transition or start from here.
  • Transitions and Animations tabs with an Animation pane; View ▸ Notes, Master, Sorter and Outline.
  • Find and replace, comments in the Review panel, header and footer, slide number and other fields, QR codes.
  • Drop in reusable Components (cards, timelines, callouts) from the components panel.
  • Anchor a shape to a live metric; the number in the deck follows the sheet.

Agents

wos-gen pptx with layouts (cover, section, bullets, table, chart, closing) and a theme; the recipe in the agent's guidance builds a deck whose numbers stay bound to the spreadsheet.

CSV and data

A CSV opens straight into the spreadsheet engine with its delimiter sniffed, and saves back in its own dialect.

Notes and code

Markdown, text, code and JSON open in an editor with a live markdown preview; links between notes become a graph.

What you can do

  • Switch between Edit, Split and Preview with the segmented control on the toolbar.
  • Write with a markdown toolbar and a live preview that also renders live transclusions.
  • Link notes with [[Note]]; see backlinks and related notes under Knowledge.
  • HTML files render with a preview and code toggle; images, video and audio open in place; a .wcanvas file is an infinite canvas.

Reach it

Open any .md, .txt, .json, .yaml or code file from Files or ⌘P.

Library and the wiki

Your files, your notes and what your agents remember, behind one button, and a wiki that writes itself from the documents you give it.

What you can do

  • Switch Files, Notes and Memory at the top right.
  • Notes lists every note and the notes that are linked but not written yet; Open the graph lays them out.
  • Wiki: Add files… (or right-click a file → Add to the wiki). The app reads each document and writes a page per person, organisation, project and topic, plus an index, linked with [[links]].
  • Edit any wiki page; the next update builds on your edit. Read again after a source changed; Undo takes back one update; pages stay when their source is gone.

Reach it

Library in the dock.

Costs

The wiki reads documents with your default model, so it uses your Claude subscription and takes a moment per file.

Chat

A conversation with Claude inside your workspace: your past chats on the left, the conversation in the middle, and anything it makes on the right.

What you can do

  • Start a New chat; search earlier chats by what was said.
  • Attach files with the clip, by dragging them in, or by pasting; @ mentions a file, / runs a skill.
  • Preview what it made (pages, images, documents, tables) and open it in the workspace.
  • Beside your work keeps the chat next to a document or the browser; Back to Chat brings it home with its history. Stop ends a reply.

Reach it

Chat in the dock · the stage's Chat button · in the browser, type into Ask about this page….

Good to know

Chat runs on your Claude subscription. Chats are kept per workspace.

Mail

A full native mail client that also sorts the inbox for you, and lets agents draft while you send.

What you can do

  • Read and send over IMAP and SMTP, several accounts, folders, search, archive, star, unread, undo-send, drafts, signatures.
  • Sift: one pass sorts new mail into zones (needs a reply, your cases, worth a glance, noise). Every row carries its verbs; "not right?" teaches a permanent sender rule.
  • Triage proposes filing; Newsletters sweeps subscriptions into one place, never moving anything on its own.
  • Mail that needs a reply also waits in the Inbox: answer it in Mail or dismiss it there.
  • Rich compose: arrangeable blocks, headings, images, live metric values, live tables, table-cell charts, your brand kit, split editor and preview.

Reach it

Rail Mail. Add an account with provider presets or Google and Microsoft sign-in; or try the offline demo mailbox.

Agents

Agents read and draft replies; drafts arrive as cards in Agents and on Home. Sending is always yours.

Calendar

Your real calendars, editable, with invitations actually sent by the server.

What you can do

  • Create events with an inline calendar picker; open details; edit surgically so attendees and alarms survive; drag to reschedule in 15-minute steps; two-step delete.
  • Recurring series with per-occurrence changes; attendee replies shown as marks; add or remove attendees.
  • Sources: CalDAV (iCloud, Fastmail, Nextcloud) read and write, local .ics, subscribed feeds, Google and Microsoft read-only.
  • An Ask box on the surface lets you say "move Thursday's review to 3" in words.

Reach it

Rail Calendar · Add calendar top right.

Agents

wos-action run calendar.createEvent schedules; the next event is pinned on Home.

Browser

A real Chromium browser inside the window, with an assistant that reads the page, and that agents can drive while you watch.

What you can do

  • Tabs and tab groups, find in page, zoom, bookmarks, history search, session restore.
  • Deep-read this site: a bounded multi-page profile; ask a question about the page.
  • Sign in to a site once; the session persists, and agents work there as you (see Connectors).
  • Downloads button: open a download or show it in its folder. A tab an agent is using shows that agent's name.
  • Type into Ask about this page… to open a chat about the page beside it.

Agents

Navigate, click, type, extract, map, screenshot and deep-read through wos-action run browser.*. Research fans out one tab per helper. Links from mail and agents open here on their own.

Agents

Your specialists, and the place where their work waits for your decision.

What you can do

  • Team: run a specialist in a fresh agent tab; open one to read how it thinks; forge a new one from a description and approve the proposal.
  • Feed: review runs with inline diffs, answer live permission requests, keep or revert. Mail drafts arrive here too. The reward is queue zero.
  • Fleet: see every lane at once and approve all reversible work in one go.
  • On the landscape, click an agent to see its work; its Settings tab edits About and Instructions, the Model, Asks first or Just does it, and what it can use; Save or Delete.

Reach it

Rail Agents · ⌘⇧A focuses the agent · Menu Agent ▸ New Agent, Checkpoints, Mode, Run Skill.

Safety

A checkpoint is taken before every agent write; Revert rolls it back. Safe mode reads and generates only; Full mode edits and runs commands with destructive ones blocked.

Apps

Small tools you make yourself. Describe one in a sentence; it is planned, built and tested in front of you, then waits in a gallery for you to use, also full screen.

What you can do

  • New app or Describe a new app: type the idea. A short product brief comes first, then the build.
  • Watch it work: the preview reloads after every step, and the builder clicks through its own app to test it; three suggested next steps follow.
  • Open an app from its card: Full screen (Esc returns), Edit with chat, Duplicate, Export as a .wosapp file without its data; Import… shows what an app may do before you add it.
  • Add a ready-made app: SVG Generator, Fact Checker, Devil's Advocate, Illustrator Light, Hairline.

Reach it

Apps in the dock. A workspace folder must be open.

Safety and cost

Apps run sealed off: no internet, no browser storage, no files except ones you pick in an Open or Save dialog, and AI only when the app declares it. The builder may change only that app's folder (Apps/<name>/). Building, and the AI answers inside an app, use your Claude subscription; a build takes a few minutes.

Inbox

One place for everything that waits on you, and a history of what happened.

What you can do

  • Allow or deny an agent that asks; keep (Mark accepted) or Revert a finished run, or Revise it with a note.
  • Answer mail that needs a reply in Mail, or dismiss it.
  • Keep, correct or forget a memory an agent suggested.
  • Switch Waiting and History at the top right.

Reach it

Inbox in the dock; the badge counts what waits.

Routines

Menu → Agents → Routines. Agents on a clock. Each run lands in the Feed for you to look over; nothing is sent on its own.

What you can do

  • Create a routine: a name, what it does, when (every day, weekday, week, or every few hours), which agent, and exactly what it may reach.
  • Turn it on or off, run it now, edit, delete. Last and next run are shown on the row.
  • Missed runs catch up once when the app opens; a routine never stacks on top of itself.

Under the hood

Routines are background runs owned by the app, not a window: they survive the window closing, run in safe mode, and can only reach the capabilities you ticked. A run that needs you sends a notification.

Cockpit

Standing back from the work. Three views on the same data: what needs you now, what happened, and how it connects.

What you can do

  • Fly between altitudes: Head-of, Team-lead and Agent are live; CEO is a preview preview.
  • Re-slice with the lens; open a case from any view, one move away.
  • Stream: group by day, case, agent or kind; jump to a case or file.
  • Map: click a document to open it, a case to land on it.

Reach it

Menu → Cockpit (it opens on the stage) · Home, Stream, Map at the top. What needs you and the stream also show in the Inbox; Cases has its own Map and Board.

Cases

The thread a piece of work leaves behind: its documents, its notes, its status, in a plain markdown file you own.

What you can do

  • Create a case, move it through its stages, add notes, attach files, ask an agent to work on it.
  • Offers the notes imply (research a person, prepare for the meeting, put it on the calendar) appear as one-tap suggestions.
  • Tag a prompt with #case in the prompt bar to give the agent the case as context.

Where they live

Cases/*.md in the workspace, or global. Home and the cockpit read the same files.

Agents

wos-case new · ls · get · note · attach · status · view, so terminal work lands in a case, not loose files.

Sessions

A session is one continuing conversation with an agent that remembers the earlier turns. Keep it as a case and the case records what you asked, the outcome and the files made, not the full transcript. Settings → Agents → Keep sessions as cases: Always, Suggested or Manually. Each case has a work folder, Work/<case>/, with sources, drafts and outputs; agents write drafts there and you move what you accept to outputs.

Cases in the dock (Shelf, Map, Board, Sessions) · All work on the landscape.

Terminal dock

A real shell and a real agent, docked bottom or right, that already know where you are.

What you can do

  • Open with ⌘J; ⌥⌘J minimises to a title bar that keeps the session alive.
  • Dock it at the bottom or the right, or let it float as a window you move and resize.
  • Agent tabs run Claude with the live harness: the root, the surface you are on, the open file, and the actions that surface offers.
  • Per-surface quick-action chips; files the agent touches become chips that open in the editor.
  • Tabs, transcripts and the feed belong to the open workspace and return when you come back to it.

Reach it

⌘J · Terminal in the dock · Settings → Workspace → Terminal · Menu View ▸ Toggle Terminal, Agent ▸ New Shell.

Knowledge

Your notes as a connected web instead of loose files.

What you can do

  • See what links to the open note and where it links; jump either way.
  • Related notes are found by shared links, no model involved.
  • Stubs list [[links]] to notes that do not exist yet, so you can create them.
  • Graph view lays the whole web out.
  • Agents can search the workspace and read Word, Excel, PowerPoint and PDF files as text; the wiki writes linked pages from documents.

Reach it

Rail Knowledge, with a note open · a document's Show backlinks action.

Agents

wos-action run knowledge.search and the Knowledge capability.

Memory

What the workspace has learned, so agents and you both remember, and you stay in charge of what is kept.

What you can do

  • Tell it something worth remembering; search; filter by kind; forget an entry.
  • Keep, Correct or Forget what an agent suggested; until you keep it, it is marked "not kept yet" and waits in the Inbox.
  • Correct an entry; the earlier text stays as its history.
  • After a session has been quiet for ten minutes, up to three memories are suggested from it; a daily tidy merges repeats and drops suggestions you did not keep after 30 days (Tidy now runs it at once).

Reach it

Library → Memory · Menu → Memory · suggestions in the Inbox.

Finding by meaning

Memory finds entries by meaning as well as by words, in English and German, with a model of about 120 MB downloaded once. The model runs on macOS (Apple Silicon) and on the Windows and Linux builds (x64). Settings → Agents → Learn from sessions turns the suggestions on or off (on by default). Every run gets your kept preferences.

Connectors

Everything the workspace is signed into, on one page, with what to click when a sign-in dies.

What you can do

  • Turn MCP connectors on or off and store their keys; keys are written into the keychain and never shown again.
  • Connect OAuth services (Sentry, Linear, Asana) through the system browser.
  • Sign in to a site: you log in on the real site in a browser tab; only the session is kept, and agents then work there as you.
  • Mail, calendar and Drive accounts show with a status computed by trying a real refresh; Check again re-probes.

Catalog

GitHub, Filesystem, Postgres, Brave Search, Slack, Notion, Tavily (keys); Sentry, Linear, Asana (OAuth); Google Drive; any site.

Settings

The few switches that change how the whole app behaves.

  • Appearance: theme (light, dark or follow the system) and landscape graphics (Auto, Full, Light, Off).
  • Workspace: Open on Landscape or Stage, and where the terminal sits (bottom, right or floating).
  • Agents: default and quick-task models, Codex, agent mode, Keep sessions as cases, Learn from sessions.
  • Notifications: an agent is asking · a routine needs a look · a case is waiting on you (off by default) · a sign-in died. One per thing per ten minutes.
  • Brand: colours, fonts, logo and voice that steer rich mail and generated documents.
  • System: whether the office engine, the document generator and the Claude CLI were found.

Find and run

Live links, safety, and the rest

Live transclusion

One number or table lives in one place and stays true across spreadsheets, documents, decks, mail and notes. A metric is read from a cell and linked into a deck shape or a document field; sync pushes the value into every linked file on disk. A broken link shows a visible placeholder, never a wrong number.

Checkpoints and revert

Before an agent writes, a shadow checkpoint is taken. Every card in the Feed can be kept or reverted; Agent ▸ Checkpoints lists them with diffs.

Notifications

Local notifications for the four things worth an interruption, throttled to one per thing per ten minutes. A click lands on the rail the thing lives on.

Snapshots

File ▸ Snapshots saves and restores the whole desk: open files, the active one, panel layout.

Updates

A banner appears only when there is an update; Workspace OS ▸ Check for Updates.

Agent commands

Every agent run has these on its PATH. They are how an agent reaches the app without touching anything it was not given.

CommandWhat it does
wos-genBuild a real .pptx, .xlsx or .docx from a JSON spec. The file opens in a tab when it lands.
wos-metricCreate, read, set, link, refresh and sync live metrics and ranges across every linked file.
wos-collectionTyped record sets with filtered, sorted views linked into tables and ranges; sync updates them.
wos-caseCreate and update cases: note, attach, status, view.
wos-actionDrive the live app: list, context, run. Every action is non-destructive; it can never send or delete. Each run carries a token and can only run what its grant allows. Among the actions: knowledge.search, knowledge.read (office files as text), knowledge.wiki-add, memory.search and memory.remember.
wos-mcp-tokenMint the current bearer for a remote OAuth connector; never logs a secret.

Windows and Linux

Releases are for macOS. Builds for Windows 11 and for Linux (including WSL) exist on the fork cbruyndoncx/Workspace-OS; they work the same way, with these differences.

  • Install: Windows uses a short winget block and an installer, Linux the distribution's packages; see docs/WINDOWS.md and docs/LINUX-WSL.md.
  • Office engine: not bundled; the app uses the LibreOffice you install. On Windows, spreadsheets render black on LibreOffice 25.8 and later until LibreOffice fixes bug 174143; a second copy of LibreOffice 25.2 used only by Workspace OS works around it.
  • Keys: Ctrl where the Mac uses ⌘ (see Keyboard).
  • App data: %APPDATA%\workspace-os on Windows, ~/.config/workspace-os on Linux.
  • Updates: none automatic; install a newer build by hand.

Not yet

Honest edges as of v0.2.26. Team chat (Teams, Slack) is not built; the Chat in the dock is a conversation with Claude. The Cockpit's CEO altitude is a preview on mock data; Head-of, Team-lead and Agent are live. Google paths (Gmail, Drive, Calendar write) wait on a client id, and Google and Microsoft calendars are read-only. Calendar has no agenda list or event search yet, and new recurrence rules cannot be authored. Image generation is not built. Releases are not notarized.
